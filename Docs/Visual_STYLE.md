# ArmyRush Visual Style Guide

Version: 1.0
Status: Source of Truth

---

# Purpose

This document defines the complete visual direction of ArmyRush.

This document exists to ensure that every asset, environment, UI element, effect, animation, material, and scene follows a consistent visual identity.

ArmyRush is targeting the visual appeal and readability of the most successful mobile runner and crowd battle games while maintaining its own production-quality presentation.

This is NOT a prototype document.

This is NOT a placeholder document.

Everything defined in this file represents production-ready expectations.

If a feature is considered complete, it must visually meet the standards defined here.

---

# Visual Design Pillars

Every visual decision should reinforce:

1. Clarity
2. Readability
3. Satisfaction
4. Performance
5. Mobile-first design
6. Instant recognition
7. Strong visual feedback
8. Mass-market appeal

The player should instantly understand:

* What is good
* What is bad
* What increases power
* What decreases power
* What can be destroyed
* What can be collected
* What should be avoided

Within 1 second of seeing the screen.
